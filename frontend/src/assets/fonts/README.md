# Bundled fonts

These unmodified fonts load from the app bundle, without network access.

- Inter Variable 4.1: https://github.com/rsms/inter/tree/v4.1/docs/font-files
  (`InterVariable.woff2`), SIL Open Font License in `Inter-LICENSE.txt`.
- JetBrains Mono 2.304: https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/webfonts
  (`JetBrainsMono-Regular.woff2`), SIL Open Font License in `JetBrainsMono-OFL.txt`.

Inter is used for interface text and plain text previews. JetBrains Mono is used
for code and command previews, with ligatures disabled to keep symbols literal.
The license texts are also included in `packaging/linux/THIRD_PARTY_NOTICES.txt`.
